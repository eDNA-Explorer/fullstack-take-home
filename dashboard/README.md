# Genomic Sample Dashboard

A Next.js dashboard for visualizing genomic sequencing data processed by the Dagster data pipeline.

## Overview

This dashboard displays:
- Sample statistics (Q20, Q30, read counts, etc.)
- Sequence counts per sample
- Summary metrics across all samples

## Getting Started

```bash
bun install
bun dev
```

The dashboard will be available at http://localhost:3001

## Project Structure

## Tech Stack

- **Framework**: Next.js with App Router
- **Runtime**: Bun
- **Data Layer**: tRPC with React Query
- **UI Components**: shadcn/ui (Radix primitives)
- **Styling**: Tailwind CSS v4
- **Charts**: Recharts
- **Parquet Reading**: parquetjs-lite

## Data Integration

The dashboard reads Parquet files generated by the data pipeline from `../data-pipeline/output/`:

- `sample_stats.parquet` - Quality metrics per sample (Q20, Q30, etc.)
- `sequence_counts.parquet` - Unique sequence counts per sample

## Technical Notes

### Parquet Compatibility

The `parquetjs-lite` library has limited encoding support. Parquet files from the data pipeline must be written with:

```python
df.write_parquet(path, use_dictionary=False, version="1.0")
```
